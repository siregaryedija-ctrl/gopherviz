# Changelog

## 1.0.0

The first public release.

- **8 languages, all simulated:** Go, JavaScript, TypeScript, Python, PHP, C++, C and Java. Your code is never executed.
- **Live pixel-art stages** for loops, if/else, switch, functions and recursion, classes and objects, multi-file
  programs, arrays and sorting, searching, maps, pointers, stacks and queues, grids and mazes, graphs, trees,
  goroutines and channels, and the JavaScript event loop.
- **Real values** for every variable, condition and line of output, with the running line highlighted in the editor.
- **Error scenes** that explain crashes in plain words, with a tip on how to fix them.
- **Guess mode:** the panel pauses at key moments and asks what happens next.
- **Algorithm race:** two functions sort the same random list side by side, with a growth chart and a Big-O estimate.
- **Recording** to GIF, MP4 or WebM, as the stage alone or as a 9:16 reel with code and output.
- **Themes** (Day, Night, Cave, Beach) with moving backgrounds and their own chiptunes, a smooth-background option and
  custom music files.
- **Input box** for programs that read user input, with random numbers for values left empty.
- The panel can live in an editor tab, the sidebar or the bottom panel.
- All text in the panel, settings and messages is in English. Settings saved with the old Indonesian theme names
  (`siang`, `malam`, `gua`, `pantai`) keep working.
